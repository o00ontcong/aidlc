# Remember — $ARGUMENTS

Write `MEMORY-HANDOFF.md` (maximum 64 KiB) with a visible `unreviewed` trust
label, source artifact links, short durable facts and open questions. Core scans
the handoff for credential patterns and rejects unsafe or oversized content. Do
not include full logs or instructions that modify `CLAUDE.md`, rules, skills or
policy. Memory is context only; Canvas cannot promote it into policy.
