# TodoKit — AIDLC iOS Demo

App demo: Swift Package trong `src/`, build bằng `swift build`, test bằng `swift test`.

Đọc `README.md` để biết hai pipeline và 5 epic đã seed.

## Quy tắc

- Business rule sống trong `TodoStore`, **không** trong View.
- Chưa `Build complete!` + test xanh thì chưa coi là xong step `implement`.
- Không nới lỏng assertion để test pass — sửa code.
