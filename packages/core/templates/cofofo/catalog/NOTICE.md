# CoFoFo curated ECC subset

Source: Everything Claude Code by Affaan Mustafa, commit
`d8409a4b0813771235555e32e3d8046a73988bfa`, MIT License.

AIDLC selected and shortened the files in this directory for a provider-neutral,
text-only CoFoFo workflow. Tool declarations and harness-specific directions
were removed; no upstream hooks, validators, scripts, or executable assets are
included. AIDLC owns and tests every executable validator used by the workflow.
