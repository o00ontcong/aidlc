# Security review

Inspect trust boundaries, secrets, input validation, authorization, storage,
network policy, dependency changes, logging, and path handling. Treat generated
or fetched content as untrusted. Give evidence-backed findings with severity;
do not claim a scan or command ran unless its machine evidence exists.
