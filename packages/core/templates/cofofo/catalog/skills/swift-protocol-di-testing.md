# Swift protocol DI testing

Put side effects behind narrow protocols and inject implementations through
initializers. Prefer deterministic fakes over network, clock, or global state.
Keep decisions in Domain/Data layers and presentation declarative. Exercise
success, failure, and boundary behavior with async XCTest where appropriate.
