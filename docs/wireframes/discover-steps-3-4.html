Mục 3 & 4 — luôn đọc như project đã có code

Một cách trình bày. Project mới không phải case riêng: mọi FR / feature đều nằm ở cụm chưa làm. Khi có source, một số mục chuyển sang đã có trong code hoặc docs lệch.

Mục 3 dưới đây là bản duyệt “đã có code”. Mục 4 cần cây — không chỉ list — và mỗi nhánh mang status.

3 · Requirements — project đã có code

Một hành vi / dòng, id FR-xx. NFR là ràng buộc, không xếp “đã làm”. Heading giữ nguyên; dòng trống tách ba cụm trong cùng section.

product/REQUIREMENTS.md
Functional · đã có trong code
FR-01User có thể mở video local.
FR-02User có thể nạp subtitle #1.
FR-03User có thể nạp subtitle #2.
FR-04Hai subtitle hiển thị đồng thời.
Functional · chưa làm (project mới = cả list ở đây)
FR-06User xuất clip 30 giây quanh cue hiện tại.
Functional · docs lệch code
FR-05Mỗi subtitle chỉnh được timing offset — code đang một offset chung.
Non-functional requirements
NFR-PERF-01Seek dưới 200ms trên file 2GB.
NFR-OFFLINE-01Chạy hoàn toàn offline.
## Functional requirements

- **FR-01** — User có thể mở video local.
- **FR-02** — User có thể nạp subtitle #1.
- **FR-03** — User có thể nạp subtitle #2.
- **FR-04** — Hai subtitle hiển thị đồng thời.

- **FR-06** — User xuất clip 30 giây quanh cue hiện tại.

- **FR-05** — Mỗi subtitle chỉnh được timing offset. (docs lệch: code một offset chung)

4 · Feature tree — status trên từng nhánh

List phẳng khó thấy phạm vi. Cây giữ topology (Video / Subtitle / Export); lá là feature F-* và mang status. Nhóm cha hỗn hợp khi con khác màu.

Cây feature

4 feature 2 đã có 1 chưa làm 1 lệch
  • Videođã có
    • Open / Play / Pause / Seek F-VIDEO-01 FR-01 đã có trong code
  • Subtitlehỗn hợp
    • Nạp hai SRT, hiện cùng lúc F-SUB-01 FR-02 · FR-03 · FR-04 đã có trong code
    • Offset từng subtitle F-SUB-02 FR-05 docs lệch code
  • Exportchưa làm
    • Xuất clip 30 giây quanh cue F-EXP-01 FR-06 chưa làm

Cùng một FEATURES.md

Cây ASCII trong ## Feature tree có thể ghi status cạnh lá (✓ / ○ / ⚠) — viewer tô màu từ đó. List ## Features vẫn là nguồn id + cite FR. 

## Feature tree

```text
Video                          ✓ đã có
└── Open / Play / Seek         F-VIDEO-01

Subtitle                       hỗn hợp
├── Load two SRT               F-SUB-01  ✓
└── Offset                     F-SUB-02  ⚠ lệch

Export                         ○ chưa làm
└── Clip 30s                   F-EXP-01
```

## Features

- **F-VIDEO-01** — Mở, phát, pause, seek — FR-01.
- **F-SUB-01** — Nạp hai SRT và hiện cùng lúc — FR-02, FR-03, FR-04.
- **F-SUB-02** — Offset từng subtitle — FR-05. (docs lệch)
- **F-EXP-01** — Xuất clip 30 giây — FR-06.
